## Papers and code

**Prithvi Raghu**. I research quantum machine learning and scientific computing.

I study quantum circuits for learning, games and option pricing. I also model HF propagation for emitter geolocation.

* [Quantum games (QHD)](https://github.com/Prithvi8706/Multiplayer-QHD-Game): restricted GHZ equilibria admit unrestricted deviations, with compact payoff evaluation and recorded IBM Heron experiments in a co-authored manuscript. [QHD manuscript](https://github.com/Prithvi8706/Multiplayer-QHD-Game/blob/main/paper/qhd.pdf)
* [Quantum ML (FQCNN)](https://github.com/Prithvi8706/Fully-Quantum-Native-QCNN): coherent-pooling equivalence and four-task simulator benchmarks, with classical-baseline comparisons documented in a co-authored manuscript. [FQCNN manuscript](https://github.com/Prithvi8706/Fully-Quantum-Native-QCNN/blob/main/paper/fqcnn.pdf)
* [Option pricing (QOP)](https://github.com/Prithvi8706/quantum_option_pricing): Asian-basket encodings trade qubits against gate count, with reproducible logical-resource comparisons and a manuscript draft. [QOP draft](https://github.com/Prithvi8706/quantum_option_pricing/blob/main/manuscript/2026-09-22/main.md)
* [HF geolocation](https://github.com/Prithvi8706/Real-Time-Ionospheric-Geolocation): a two-pass geolocation pipeline and Gaussian-process correction, evaluated on simulated emitter geometry with explicit limitations. [Hybrid model](https://github.com/Prithvi8706/Real-Time-Ionospheric-Geolocation/blob/main/models/hybrid_model.py)
